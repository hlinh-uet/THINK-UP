# Manrope

`Manrope-Variable.ttf` is the active self-hosted font, with a `wght` axis from 200 to 800 and full Vietnamese coverage. CSS declares the complete weight range so intermediate UI weights render consistently.

Source: https://github.com/google/fonts/blob/main/ofl/manrope/Manrope%5Bwght%5D.ttf
Retrieved: 2026-10-17.
License: SIL Open Font License 1.1, included in `Manrope-OFL.txt`.

The earlier static Regular/Bold files are retained; current CSS uses only the variable font. No runtime requests to external font services are required.
